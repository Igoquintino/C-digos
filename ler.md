### Descrição do código

No momento, o código implementa as árvores binárias de "CPF" e "NOME". No entanto, ainda faltam as funções de busca e remoção por CPF, pois essas funcionalidades ainda não foram desenvolvidas.

O código principal (`main`) está funcionando corretamente, utilizando um menu de opções baseado em `switch-case`. Esse menu segue um fluxo normal, mas precisa de melhorias para tornar a interação mais intuitiva.

Vale ressaltar que, na implementação atual, o código permite inserir, buscar e remover dados usando uma busca binária em árvores binárias. As árvores são criadas à medida que o usuário vai inserindo os dados de novos usuários.
